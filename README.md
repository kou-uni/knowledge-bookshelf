# Knowledge Bookshelf

A digital library application for organizing and analyzing knowledge sessions.

## Features
- **Project & Session Management**: Organize work into volumes and chapters.
- **AI Analysis**: Extract insights using structural and reflective analysis.
- **Multimedia Input**: Support for Text, Voice, PDF, and Photos.
- **Output Generation**: Create presentations and summaries.

## Tech Stack
- Next.js 13 (App Router)
- Vercel Postgres
- OpenAI GPT-4o
- Geist UI

## Deployment
Deployed on Vercel.
